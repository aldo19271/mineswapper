## 🚀 Cara Menjalankan

### 1. Mainkan Langsung di Browser (Rekomendasi!)
Kunjungi situs berikut:
👉 **[https://aldo19271.github.io/mineswapper/](https://aldo19271.github.io/mineswapper/)**

Cukup klik tautan di atas, dan game akan langsung terbuka.  
- Di **Desktop**, Anda akan mendapatkan papan ukuran **14x18** dengan 45 bom.  
- Di **Mobile** (lebar layar ≤ 640px), otomatis berubah menjadi papan **6x6** dengan 8 bom agar nyaman disentuh.
